# 2026-11-03 实测（本机）：纯编码环节 vips 比 PIL 慢 35–45%
#   PNG 1080x1350：vips 15ms / PIL 11ms
#   PNG 4000x5000：vips 148ms / PIL 102ms
# 原因是 PIL→vips 必须整图拷贝一次，该开销大于 vips 编码省下的部分。
# 真正能体现 vips 优势的是「合成+写盘一体化、中间不物化」的流式管线，
# 当前架构是「先合成为 PIL Image 再编码」，用不上。
# 代码保留在 app/utils/vips_export_engine.py，需要时用
# BTPW_ENABLE_VIPS_ENCODE=1 或 job.backend="vips" 显式启用。
# 安装：pip install pyvips-binary  （自带 libvips 运行时，Windows 上最省事）
