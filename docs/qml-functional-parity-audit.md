# QML 功能对齐审计

## 审计目标

本审计以现有 QWidget 主程序的用户能力为基准，评估 QML 工作台是否已经接入真实业务模型和执行链。视觉占位不算功能完成；只有能够修改真实 `Document`、参与保存/加载、预览和导出的能力才记为已完成。

状态定义：

- **已完成**：核心流程已经接入真实模型，并有自动化测试覆盖。
- **部分完成**：主路径可用，但高级参数、异常流程或跨文档能力尚未对齐。
- **未接入**：界面缺失或仍为占位交互。
- **暂缓**：不阻塞主编辑与导出流程，待核心能力稳定后处理。

## 已验证的真实链路

QML 当前已经通过 `WorkspaceViewModel` 使用真实 `Document` 和图层类，而不是单独维护一份演示数据。以下链路已有测试覆盖：

- `.cmp` 保存/打开与文档属性同步。
- 图片、素材文件夹和文字图层内容源。
- 文字系统字体搜索、字号、粗斜体、对齐、横竖排、行字距和文本框行为。
- 文字纯色/线性/径向/角度渐变、背景、描边、阴影、发光和整段选区局部颜色。
- 跨文字图层的样式复制粘贴，保持文案内容和图层几何不变。
- 图片填满裁剪、完整显示、原始尺寸、五向裁剪锚点和水平/垂直翻转。
- 画布选择、拖动、自由/等比缩放、旋转与基础对齐。
- 图片与异形图层随机位置、随机缩放、随机旋转、运行时重新抽样及 `.cmp` 往返。
- 图层复制、层级移动、删除、撤销和重做。
- 真实异形图层创建、五种形状切换、梯形和多边形参数。
- 混合模式、描边、圆角、颜色叠加和线性渐变。
- 真实预览、单图导出和异步批量导出。

## 实施路线

1. **文档闭环（已完成）**：真实多标签、新建画布、切换、关闭确认、会话状态隔离。
2. **图层闭环（进行中）**：异形图层基础、图片主要属性、文字排版/外观和样式复制粘贴已完成；继续补自由裁剪与自由路径。
3. **编排能力**：多选、分组、批量对齐与分布。
4. **画布效率**：参考线、标尺、画布尺寸和预设管理。
5. **数据组合**：绑定组和尺寸匹配。
6. **导出对齐**：高级单文档批量导出和多标签批量导出。

每一阶段均要求功能进入真实模型、可持久化、可撤销时接入历史，并覆盖预览与导出一致性测试。
