# QML 功能对齐审计

## 审计结论

QML 工作台已经接入真实 `Document`、图层、预设、绑定、尺寸匹配和导出模型。除用户明确暂缓的 AI 功能外，旧版菜单和生产工作流均已有可操作入口，界面操作进入既有保存、历史、预览和渲染链路。

采用兼容优先的混合架构：高频编辑功能使用原生 QML；仍依赖复杂 QWidget 表单的能力通过 `LegacyFeatureBridge` 打开成熟窗口。两套界面共享同一批 `Document` 实例，不复制渲染、导出、预设、绑定或尺寸匹配逻辑。根目录 `main.py` 默认启动 QML，`--classic` 可回退到旧版主窗口。

状态定义：

- **已完成**：核心流程接入真实模型，并有自动化测试覆盖。
- **已完成（有限制）**：核心生产流程可用，存在已写明的非阻塞限制。
- **暂缓**：不属于本轮核心对齐范围。

## 已验证链路

- 真实多标签 `Document` 会话，以及 `.cmp` 保存、打开、撤销和重做。
- 图片、文件夹、文字和异形图层的创建、编辑、编排、分组与序列化。
- 自由裁剪、矢量节点、参考线、画布预设和项目预设的交互合约。
- 文字排版与外观、图片外观、随机变换及跨文字图层样式复制。
- 绑定组合预览、组合一致性、尺寸匹配与自动遮罩在 `FastRenderer` 中真实生效。
- 单图、单文档批量和多标签批量导出，共用现有高质量渲染与执行器。
- 文件、编辑、图层、画布、视图菜单、旧版快捷键、应用退出确认和标签页右键操作。
- QML 会话与旧版高级窗口共享文档；预设中心可读取和保存全部 QML 标签页。
- 1280x760 与 1600x960 窗口尺寸下的工作台、抽屉和弹窗视觉验收。
