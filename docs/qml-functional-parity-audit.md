# QML 功能对齐审计

## 审计结论

QML 工作台已经接入真实 `Document`、图层、预设、绑定、尺寸匹配和导出模型，能够承担批图王的核心编辑与批量导出工作。界面操作会进入既有保存、历史、预览和渲染链路，不再是独立原型数据。

本轮对齐以 QWidget 主程序的核心生产流程为范围。AI 素材、诊断工具、标签拖拽排序和上次会话自动恢复等辅助能力不阻塞编辑与导出闭环，继续保留在后续迭代范围内。

状态定义：

- **已完成**：核心流程接入真实模型，并有自动化测试覆盖。
- **已完成（有限制）**：核心生产流程可用，存在已写明的非阻塞限制。
- **暂缓**：不属于本轮核心对齐范围。

## 已验证链路

- 真实多标签 `Document` 会话，以及 `.cmp` 保存、打开、撤销和重做。
- 图片、文件夹、文字和异形图层的创建、编辑、编排、分组与序列化。
- 自由裁剪、矢量节点、参考线、画布预设和项目预设的交互合约。
- 文字排版与外观、图片外观、随机变换及跨文字图层样式复制。
- 绑定组合预览、组合一致性、尺寸匹配与自动遮罩在 `FastRenderer` 中真实生效。
- 单图、单文档批量和多标签批量导出，共用现有高质量渲染与执行器。
- 1280x760 与 1600x960 窗口尺寸下的工作台、抽屉和弹窗视觉验收。

## 后续范围

1. 决定 QML 是否正式替换 QWidget 主入口，再迁移 AI 素材、设置和诊断工具。
2. 增加标签拖拽排序与上次会话自动恢复。
3. 评估文字沿路径排版及少量高级效果参数的真实用户优先级。
4. 在发布前执行 PyInstaller 单文件打包和 `dist/批图王.exe` 人工验收。
