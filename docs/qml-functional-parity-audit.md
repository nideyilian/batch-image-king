# QML 功能对齐审计

## 审计结论

QML 工作台已经按旧版行为契约完成非 AI 主流程修复。完成标准不再是“存在同名入口”，而是对象创建时机、合法空状态、创建前后参数、模式切换、默认几何、画布交互、快捷键和后台任务生命周期均与旧版一致。

采用兼容优先的混合架构：高频编辑功能使用原生 QML；新建画布、文字/异形创建、项目预设、批量导出、绑定和尺寸匹配通过 `LegacyFeatureBridge` 复用成熟窗口。QML 只负责表现和会话适配，不重新定义这些业务规则。根目录 `main.py` 默认启动 QML，`--classic` 可回退到旧版主窗口。

## 行为契约修复

- 普通图片图层恢复为立即创建 `200x200` 空对象，默认 `(0, 0)`、文件夹模式、无来源；来源类型可独立切换。
- 文字和异形图层恢复创建前完整配置，异形重新支持空来源及文件夹来源。
- 图层可移出画布或使用负坐标；恢复 8 个控制点、10 像素最小尺寸、旋转图层和组/多选缩放。
- 画布命中恢复透明像素、异形轮廓、分身、锁定图层、组空白区域和 `Ctrl/Alt` 穿透选择。
- 图层面板恢复视觉顶层在上，所有命令通过显式文档索引执行。
- 缩放恢复实际 `10%-1000%`，`Ctrl+0` 为 100% 并清零平移，复用 `zoom_factor/offset_x/offset_y`。
- `Ctrl+D` 恢复复制标签页，`Ctrl+L` 恢复新建空图层；重复路径、标签重命名、复制范围和最后标签关闭均按旧版处理。
- 主入口统一回到完整预设、批量导出、多标签并行导出、绑定和尺寸匹配流程；实验性 QML 抽屉不再作为生产入口。

状态定义：

- **已完成**：核心流程接入真实模型，并有自动化测试覆盖。
- **已完成（有限制）**：核心生产流程可用，存在已写明的非阻塞限制。
- **暂缓**：不属于本轮核心对齐范围。

## 已验证链路

- 真实多标签 `Document` 会话，以及 `.cmp` 保存、打开、撤销和重做。
- 空图层、独立来源模式、文字和异形旧版创建流程，以及编辑、编排、分组与序列化。
- 自由裁剪、矢量节点、参考线、画布预设和项目预设的交互合约。
- 文字排版与外观、图片外观、随机变换及跨文字图层样式复制。
- 绑定组合预览、组合一致性、尺寸匹配与自动遮罩在 `FastRenderer` 中真实生效。
- 单图、单文档批量和多标签批量导出，共用现有高质量渲染与执行器。
- 文件、编辑、图层、画布、视图菜单、旧版快捷键、重复路径标签、应用退出确认和标签页右键操作。
- QML 会话与旧版高级窗口共享文档；预设中心可读取和保存全部 QML 标签页。
- 1280x760 与 1600x960 窗口尺寸下的工作台、抽屉和弹窗视觉验收。
