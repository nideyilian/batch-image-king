# Dialog A2 弹窗规范

本文档定义批图王弹窗的 A2 规范。目标是让颜色、字体、创建、管理器、确认等弹窗使用同一套暗色层级、尺寸、按钮和布局规则，避免系统默认弹窗和各自手写样式混在一起。

## 弹窗分类

### 选择器弹窗

用于颜色、字体、文件、图层等“选一个或多个对象”的任务。

- 结构：标题 + 筛选/搜索 + 主选择区 + 预览/参数区 + 底部操作栏。
- 主选择区可以是色块网格、字体列表、文件列表或图层列表。
- 预览区只展示和当前选择直接相关的信息，不放无关说明。
- 确认按钮固定为“确定”，取消按钮固定为“取消”。

### 创建/编辑弹窗

用于文字突出、新建图层、新建画布、编辑预设等任务。

- 结构：标题 + 表单卡片 + 可选预览 + 底部操作栏。
- 如果只有一个步骤，不使用左侧导航。
- 表单标签固定宽度，输入框固定高度。
- 说明文字放在字段下方或卡片底部，不能插在按钮之间。

### 管理器弹窗

用于绑定管理器、图层大小匹配管理器、预设管理器等复杂任务。

- 结构：左侧列表/关系区 + 右侧详情/编辑区 + 底部状态/操作栏。
- 左侧负责浏览和选择，右侧负责创建、编辑和说明。
- 空状态必须明确，例如“暂无绑定组”。
- 禁用按钮要保持位置稳定，不能因为不可用而消失。

### 提示/确认弹窗

用于删除、覆盖、失败、成功等反馈。

- 标题说明结果或风险，正文说明影响。
- 主按钮使用动作动词，例如“删除关系”“覆盖文件”，不要只写“确定”。
- 破坏性动作使用警告/危险色，但仍遵守 Dialog A2 尺寸。

## 尺寸 Token

| Token | 值 | 用途 |
| --- | --- | --- |
| `OUTER_MARGIN` | 20 px | 弹窗内容外边距 |
| `CONTENT_GAP` | 12 px | 弹窗主区块之间的间距 |
| `CARD_MARGIN` | 14 / 12 / 14 / 12 px | 弹窗卡片内边距 |
| `CARD_GAP` | 10 px | 卡片内部段落间距 |
| `CARD_RADIUS` | 6 px | 弹窗卡片和内嵌面板圆角 |
| `CONTROL_HEIGHT` | 32 px | 输入框、数值框、下拉框高度 |
| `BUTTON_HEIGHT` | 34 px | 底部操作按钮高度 |
| `BUTTON_WIDTH` | 80 px | 底部操作按钮宽度 |
| `SMALL_BUTTON_WIDTH` | 56 px | 收藏、清空等短按钮宽度 |
| `FIELD_LABEL_WIDTH` | 82 px | 标准表单标签宽度 |
| `SWATCH_SIZE` | 28 px | 颜色基础色块尺寸 |
| `PREVIEW_SWATCH_SIZE` | 68 px | 当前颜色预览色块尺寸 |

## 字体层级

| Token | 值 | 用途 |
| --- | --- | --- |
| `TITLE_FONT_SIZE` | 16 px | 弹窗内容标题 |
| `SECTION_TITLE_FONT_SIZE` | 13 px | 卡片或分组标题 |
| `FIELD_FONT_SIZE` | 12 px | 字段标签、输入值、按钮 |
| `HINT_FONT_SIZE` | 11 px | 辅助说明 |

| `TITLE_BG` | `#1B2230` | 标题栏或强调标题背景 |

## 按钮规则

- 底部主按钮右对齐，主按钮在次按钮左侧或按平台习惯靠左于取消按钮。当前项目统一为“确定”“取消”并排右侧。
- 主按钮使用 `primaryButton="true"`，固定 80 x 34 px。
- 次按钮使用 `secondaryButton="true"`，固定 80 x 34 px。
- 卡片内部动作按钮高度使用 32 px，不与底部操作按钮混用。
- 禁用态保留空间，不能造成布局跳动。

## 颜色选择器

- 不再直接使用原生 `QColorDialog.getColor()`。
- 使用 `ColorPickerDialogA2`，保持中文标题和暗色样式。
- 左侧为基础色块网格，右侧为当前颜色预览、RGB/A 数值、HEX 输入。
- 色块点击、RGB/A 修改、HEX 输入必须同步到同一个 selected color。
- 取消时返回无效 `QColor()`，调用方不修改当前颜色。

## 字体选择器

- 使用 `FontPickerDialogA2` 作为统一外壳。
- 内部继续复用 `EnhancedFontSelector`，保留搜索、分类、收藏、最近字体和预览能力。
- 外壳负责 Dialog A2 标题、卡片容器和底部按钮。
- 选择过程中的字体变化只更新弹窗内部状态，点击“确定”后才应用到图层。

## 第一阶段覆盖范围

- 新增 `DialogA2` 规范 helper。
- 新增 `ColorPickerDialogA2` 并替换 UI 代码中的 `QColorDialog.getColor()` 直接调用。
- 新增 `FontPickerDialogA2` 并接入文字属性面板的字体选择入口。
- 管理器弹窗和文字突出整体布局保留到第二阶段继续统一。
