这次改了什么 changelog

两件事：图标换成 Lucide SVG 真源、弃用 shadcn 组件库。下面每一行都是实际改了代码的位置。

项目改之前改之后
图标真源icon_manager.py 内嵌 51 个手写 path + 42 个字符图标app/qml/icons/*.svg（Lucide 98 个），QWidget 与 QML 共用
图标渲染QPainter 画手写 path；缺图标时降级画字符QSvgRenderer 渲染真实 SVG，currentColor 替换为目标色
icon_manager图标实现本体退化为兼容层，64 个既有调用点零改动转调新库
shadcn 组件库app/ui/components/ 被 3 个业务文件引用弃用。业务依赖已全部解除，仅剩演示页自身
FlowLayout放在组件库 layout.py 里迁到 app/ui/flow_layout.py —— 布局原语，不是视觉组件
状态指示器把字符（✎ ● ○）拼进 QLabel 文字QLabel 贴真实 SVG 位图，颜色随状态语义
ToastQLabel 子类 + 字符图标 + QSS 背景QWidget 组合 + SVG 图标 + paintEvent 自绘背景
绑定对话框标题与分析结果里拼字符（∞ ✗ ✓）标题用 SVG 图标行；纯文本改用 [无效]/[完成] 语义前缀
怎么确认「真实应用」而不是「改了代码没生效」： 启动真实 MainWindow，遍历界面上全部 102 个按钮 —— 35 个带图标， 逐个取位图检查像素，0 个空白；图标尺寸落在 16 / 18 / 20 三档。 下面「真实界面」一栏就是那次运行截的图。
保留了什么：icon_manager.py 没有删，它退化成兼容层， 让 64 个既有调用点零改动拿到新图标。FlowLayout 从组件库里择出来 迁到 app/ui/flow_layout.py —— 它解决的是真实的按钮换行缺陷，不是视觉组件。

怎么用 usage

新代码只走下面这一套。不要再用 app/ui/components/，也不要用字符图标。

图标

from app.ui.icon_library import icon, icon_pixmap, icon_button, IconName

btn.setIcon(icon("delete")) 　　业务名，走别名表
btn.setIcon(icon(IconName.DELETE, color=Color.danger)) 　　语义常量 + 语义色
label.setPixmap(icon_pixmap("link", 16, Color.accent)) 　　贴到 QLabel
icon_button("zoom_in", size="md", tooltip="放大") 　　尺寸受 design_spec 约束

尺寸与颜色

from app.ui.design_spec import Scale, Space, Radius, FontSize, IconSize
from app.ui.tokens_v2 import Color, Typography

控件高度只准取 Scale.PX 的 24 / 28 / 36；间距只准取 Space 的 4/8/12/16/24； 图标只准取 IconSize 的 16/20/24。写死像素会被 test_ui_rules.py 拦下来。

不要做的事

✗ from app.ui.components import ... —— 组件库已弃用，有契约测试拦截
✗ IconManager.get_icon_text() —— 已废弃，字符图标已彻底移除
✗ 自己写 <path d="..."> 手绘图标 —— 与 Lucide 的几何规范对不上
✗ 在 app/qml/icons/ 放非 Lucide 来源的 SVG —— 有来源校验测试
数据来源：app/qml/icons/（98 个 SVG）、app/ui/icon_library.py（51 语义名 + 54 别名）、 app/ui/tokens_v2.py、app/ui/design_spec.py
