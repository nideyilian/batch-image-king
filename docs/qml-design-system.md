# 批图王 QML 前端设计规范与组件库

版本：2.0

状态：A 方案“生产控制台”已确认

适用范围：`app/qml/` 下的主工作台、图层面板、属性检查器、菜单、下拉框、弹窗、抽屉、预设、绑定、尺寸匹配和导出界面。

本规范是 QML 前端的视觉与交互事实来源。`docs/UI设计规范.md` 与 `docs/DESIGN_SYSTEM_SHADCN.md` 继续约束经典 Qt Widgets 前端；两套运行时不得交叉复制私有颜色或控件实现。

## 1. 设计目标

批图王服务电商运营与批量制图人员。界面采用高密度、低干扰的深色生产控制台，目标不是展示设计感，而是让用户连续工作数小时仍能快速判断当前文档、选中对象、参数状态和批量任务结果。

核心原则：

1. 高频命令一步可达，低频能力按上下文折叠。
2. 同一语义只有一种图标、术语、控件和状态表达。
3. 画布是视觉中心，界面层级不能与作品争夺注意力。
4. 颜色用于操作与状态，不用于装饰。
5. 不因视觉重构改变 ViewModel、快捷键、文档格式或导出行为。

## 2. 布局系统

### 2.1 主窗口

| 区域 | 标准尺寸 | 规则 |
| --- | ---: | --- |
| 标题菜单栏 | 42 px | 品牌、主菜单、预览状态、设置 |
| 命令栏 | 54 px | 项目、添加、排列、预览、导出命令 |
| 文档标签栏 | 36 px | 当前文档、修改状态、关闭与新建 |
| 左工具轨 | 48 px | 只放模式工具和前景/背景色 |
| 图层面板 | 276 px | 窄窗口可收缩到 246 px |
| 属性检查器 | 336 px | 1320 px 以下收缩到 302 px |
| 状态栏 | 28 px | 渲染状态、色彩空间、位置、缩放 |

窗口下限保持 1180 × 720。中央画布始终获得剩余空间；侧栏不得通过固定总宽度挤出横向滚动。画布标尺固定在视口，不随画板平移。

### 2.2 密度

- 紧凑控件高 28 px：行内图标、图层尾部操作。
- 标准控件高 30 px：输入框、下拉框、开关关联行。
- 主命令高 34 px：带图标的明确命令。
- 图标命中区不小于 28 × 28 px；主工具命中区为 36 × 36 px。
- 属性区内容左右内边距 12 px，字段间距 8 px，分区标题高 40 px。
- 不使用装饰性卡片嵌套。面板通过表面层级和 1 px 分隔线组织。

## 3. 设计令牌

运行时单一来源为 `app/qml/components/Theme.qml`。

### 3.1 表面与边界

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `bgApp` | `#0D1011` | 应用最底层 |
| `bgBar` | `#111516` | 菜单、命令、状态栏 |
| `bgPanel` | `#151A1C` | 图层与属性面板 |
| `bgRaised` | `#1A2022` | 标签、菜单、弹层 |
| `bgControl` | `#20272A` | 输入、分段控件 |
| `bgHover` | `#293235` | hover / pressed 前一层 |
| `bgCanvas` | `#090C0D` | 画布工作区 |
| `bgSelected` | `#17352E` | 选中行 |
| `border` | `#2B3437` | 分隔线、弱边界 |
| `borderStrong` | `#3B474A` | 输入和弹层边界 |
| `focusRing` | `#67E6C1` | 键盘焦点环 |

### 3.2 文本、操作与状态

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `textPrimary` | `#F3F6F5` | 标题、字段值 |
| `textSecondary` | `#AAB5B1` | 正文、普通图标 |
| `textMuted` | `#6F7C78` | 注释、单位、空状态 |
| `textDisabled` | `#4D5855` | 禁用文本 |
| `accent` | `#3BD5AA` | 主操作、选中、进度 |
| `accentHover` | `#67E6C1` | hover、焦点 |
| `accentPressed` | `#28B88F` | pressed |
| `accentSoft` | `#17352E` | 低强调选中底色 |
| `accentForeground` | `#06271F` | 强调色上的文字和图标 |
| `info` | `#5BA7FF` | 信息、参考线 |
| `warning` | `#F2B95F` | 运行、修改未保存 |
| `danger` | `#F1786D` | 错误、删除 |
| `success` | `#65D88D` | 完成、健康状态 |

状态色必须同时配合文字、图标或上下文，不得只靠颜色传达。

### 3.3 排版

- UI 正文：`MiSans`，不可用时回退到 `Microsoft YaHei UI`。
- 紧凑标题：`HarmonyOS Sans SC`，不可用时回退到正文栈。
- 数据与尺寸：`Cascadia Mono`，不可用时回退到 `Consolas`。
- 正文 12 px；属性标签 10 px；辅助信息 9-10 px；面板标题 12-13 px。
- 字距固定为 0，不随窗口宽度缩放字号。
- 文件名和图层名使用单行省略；说明和错误允许换行。

### 3.4 圆角、间距与动效

- 圆角：`radiusSmall=4`、`radius=6`、`radiusLarge=8`，业务面板不得超过 8 px。
- 间距阶梯：4、6、8、12、16、20、24 px。
- 动效：hover/focus 120 ms，展开/弹层 180 ms，使用 OutCubic。
- 动效不得改变控件尺寸或导致布局跳动；减少动画模式下允许直接切换。

## 4. 图标系统

### 4.1 来源与架构

- 图标统一使用 Lucide 线性 SVG，默认 1.8 px 视觉线宽、圆端点、圆连接。
- `AppIcons.qml` 负责语义名称和资源地址；业务 QML 只写 `iconName: AppIcons.save`，禁止写 Unicode 码点或直接资源路径。
- `AppIcon.qml` 负责尺寸、颜色、禁用态和 SVG 着色。
- `IconButton.qml` 负责按钮状态、工具提示、焦点和可访问名称。
- Python 图层模型保留旧 `glyph` 角色用于兼容，同时新增 `iconName` 角色供 QML 使用。

### 4.2 尺寸

| 场景 | 图标尺寸 | 命中区 |
| --- | ---: | ---: |
| 菜单、字段尾部 | 12-14 px | 所属行高 |
| 普通工具栏 | 16 px | 32 × 32 px |
| 左工具轨 | 18 px | 36 × 36 px |
| 空状态 | 22-24 px | 非交互 |

禁止混用填充图标、Emoji、文字符号箭头和不同粗细图标。颜色继承组件状态，不在业务层单独指定品牌色。

### 4.3 语义字典

| 分类 | 语义名称 |
| --- | --- |
| 文件 | `file-new`、`folder-open`、`save`、`save-as`、`file-image` |
| 历史 | `undo`、`redo`、`history`、`refresh` |
| 图层 | `layer-image`、`layer-text`、`layer-shape`、`layer-group`、`eye`、`eye-off`、`lock`、`unlock` |
| 编辑 | `add`、`copy`、`paste`、`trash`、`rename`、`crop`、`flip-horizontal`、`flip-vertical` |
| 排列 | `align-left`、`align-center-horizontal`、`align-right`、`align-top`、`align-center-vertical`、`align-bottom`、`distribute-horizontal`、`distribute-vertical` |
| 画布 | `pointer`、`move`、`zoom-in`、`zoom-out`、`fit-view`、`ruler`、`guides`、`magnet` |
| 数据 | `link`、`unlink`、`shuffle`、`match-size`、`sliders` |
| 反馈 | `check`、`info`、`warning`、`error`、`loader`、`close`、`more` |
| 导出 | `preview`、`export`、`batch-export`、`folder-output`、`list-checks` |

新增图标前先检查语义字典。图标名描述“含义”，不描述“长相”。

## 5. 组件库

### 5.1 `AppIcon`

API：`iconName`、`iconSize`、`iconColor`、`mirrored`。仅负责展示，不处理点击。未知名称在开发模式输出警告并回退到 `circle-help`。

### 5.2 `IconButton`

API：`iconName`、`tooltip`、`active`、`primary`、`destructive`、`buttonSize`、`iconSize`。必须覆盖 normal、hover、pressed、focus、active、disabled。纯图标按钮必须设置 `tooltip`，该值同时作为 `Accessible.name`。

### 5.3 `AppButton`

用于明确命令，变体为 `primary`、`secondary`、`outline`、`ghost`、`destructive`。一个弹窗最多一个 `primary`。当 Lucide 有熟悉图标时使用图标加短标签。

### 5.4 `AppTextField` / `AppTextArea`

标准输入控件，提供 placeholder、readOnly、invalid、errorText。focus 使用 1 px `focusRing`，选择色使用 `accentPressed`。多行文本不在失焦时意外覆盖用户输入。

### 5.5 `ValueBox`

用于数值、短文本和单位。数字值应由 ViewModel 验证范围；组件只负责编辑、Escape 恢复和提交。单位固定在尾部，不随数值长度改变布局。

### 5.6 `SelectBox` / `FontSelectBox`

- 关闭态高度 30 px，右侧使用 `chevrons-up-down`。
- 弹层与控件同宽，最大高 240 px，4 px 内边距。
- 当前项使用强调色文字和弱选中底；hover 不改变高度。
- 键盘支持上下选择、Enter 确认、Escape 关闭。
- 字体选择支持输入过滤，候选项用自身字体预览。

### 5.7 `ToggleSwitch`

只表示立即生效的二元设置。开关尺寸 36 × 20 px；必须配邻近文字标签，不能单独悬空。多项独立选择使用复选框，不用开关。

### 5.8 `SegmentedControl`

用于 2-4 个互斥、短标签模式，例如对齐、内容绑定方式、预览模式。选项等宽，容器高 30 px，当前项同时使用边界、底色和文字强调。

### 5.9 `PropertySection` / `PropertyRow`

属性分区无外层卡片，使用 40 px 标题行和底部分隔线。标题左对齐，摘要与折叠箭头右对齐。属性行标签宽 52 px，控件占余量；两组数值可同排，面板变窄时不得重叠。

### 5.10 弹层、菜单、抽屉与反馈

- `AppMenu`：原生键盘导航，菜单项高 30 px，危险操作使用 `danger` 图标与文字。
- `Dialog`：聚焦独立任务；标题区、内容区、操作区结构固定，Escape 关闭，数据丢失需确认。
- `Drawer`：用于预设、关系管理和批量导出等需要保留画布上下文的任务。
- `Toast`：短暂结果，1.8-3 秒；可操作错误不使用 Toast。
- `StatusBanner`：导出运行、成功、失败和取消状态常驻当前抽屉。
- `ProgressBar`：已知比例；未知时长使用旋转加载图标，不伪造进度。
- `EmptyState`：一个标题、一句原因、最多一个主操作。

## 6. 全界面规范

### 6.1 主界面与命令栏

- 品牌只在左上角出现一次。
- 命令按“文件、历史、创建、排列、预览/导出”分组，组间使用分隔线。
- 图标按钮保持 32 px 命中区；“新建图层”和“批量导出”使用图标加文字。
- 不同时在标题栏、工具栏和画布悬浮区重复同一高频命令。

### 6.2 图层面板

- 图层行高 56 px，结构固定为可见性、缩略图、名称/类型、锁定。
- 选中行使用 `bgSelected` 和左侧 2 px `accent`，多选不能只靠颜色。
- 层级缩进每级 14 px；折叠箭头只对图层组显示。
- 拖放目标、禁止放置和锁定状态需有明确反馈。
- 底部操作只保留新增、复制、编组、排序、删除等上下文命令。

### 6.3 属性检查器

- 顶部显示图层名、类型、序号和更多菜单。
- 所有适用于当前图层的参数分区在同一滚动区域内连续展示，不使用参数页签切换。
- 分区顺序遵循从基础编辑到外观、变换与批量规则的任务路径。
- 不支持的能力隐藏整个分区，不显示大量禁用控件。

### 6.4 弹窗与抽屉

- 新建画布、添加文字、添加异形层使用 Dialog。
- 项目预设、画布预设、绑定与尺寸匹配、批量导出使用 Drawer。
- 标题区必须显示任务名和关闭按钮；底部操作区右对齐，主操作在最右。
- 导出抽屉优先显示目录、数量、格式和开始按钮；高级性能策略默认折叠。

### 6.5 菜单与下拉框

- 主菜单使用文本，不给每项强行添加图标。
- 上下文菜单为高频编辑命令提供图标，快捷键右对齐。
- 下拉选择用于 5 个以上或较长选项；2-4 个短选项使用分段控件。
- 弹层不能超出窗口；长列表支持滚动和键盘定位。

## 7. 内容与状态

统一术语：

- 使用“新建画布”，不混用“创建文档”。
- 使用“添加图层”，不混用“插入层”。
- 使用“批量导出”，不混用“批量出图”。
- 使用“重新随机”，不混用“刷新随机/重抽”。
- 参数分区使用具体任务名称，不再以“更多参数”作为一级入口。

异步状态采用 `idle -> validating -> running -> succeeded / failed / canceled`。运行时禁用会破坏任务上下文的控件，但保留取消和查看详情。

## 8. 可访问性与键盘

- 所有纯图标按钮拥有工具提示和 `Accessible.name`。
- focus ring 始终可见，不因鼠标样式移除。
- Tab 顺序遵循从上到下、从左到右；弹窗打开后焦点留在弹窗内。
- 文字与背景以 WCAG AA 对比度为目标。
- 125% 与 150% Windows 缩放下检查长中文、文件名、单位和按钮标签。
- 破坏性操作不能只依赖红色；必须使用明确文案和确认语义。

## 9. 禁止事项

- 禁止在业务 QML 中新增界面色十六进制字面量。
- 禁止新增裸 Unicode 图标、Emoji 或私有图标字体码点。
- 禁止为了“高级感”添加模糊玻璃、发光边缘、渐变装饰和大圆角卡片。
- 禁止把页级区段包成卡片，禁止卡片嵌套。
- 禁止使用颜色代替文本状态，禁止隐藏失败原因。
- 禁止为视觉统一改写文档、图层、渲染和导出数据契约。

## 10. 验收矩阵

每次 QML UI 改动至少验证：

1. 1180 × 720、1280 × 760、1600 × 960 三种窗口尺寸。
2. 无文档、空文档、普通图片、文字、异形、图层组和多选状态。
3. 下拉框、菜单、Dialog、Drawer、Toast、运行中和错误状态。
4. 新建、打开、保存、图层编辑、预览、批量导出和多标签导出。
5. QML 源码中不新增裸图标码点；基础组件五态完整。
6. `python -m pytest` 全量通过，QML 离屏截图非空且无重叠。
