# 文字局部颜色设计

## 目标

为文字图层增加“一句文案中不同片段可设置不同颜色”的能力。第一版只支持局部填充颜色，不支持片段级字体、字号、粗斜体或其他富文本样式。

## 范围

- 文案内容继续以纯文本保存和编辑。
- 局部颜色作为独立数据保存，描述当前文案中字符范围与 RGBA 颜色。
- 未设置局部颜色的字符继续使用文字图层原有全局填充逻辑。
- 保存、加载、复制图层、预览、单图导出和批量导出需要保留局部颜色。
- 旧 `.cmp` 文件没有局部颜色数据时按现有逻辑打开。

## 非目标

- 不把 `current_text` 或 `text_lines` 改成 HTML、RTF 或 Qt 富文本。
- 不实现片段级字体、字号、粗斜体、描边、渐变或背景。
- 不改变文字绑定、随机文案、按行候选文案的现有语义。

## 数据模型

`TextLayer` 新增 `text_color_ranges` 属性，内部结构为列表：

```python
[
    {"start": 0, "end": 2, "color": (255, 0, 0, 255)},
    {"start": 2, "end": 5, "color": (0, 128, 255, 255)},
]
```

`start` 和 `end` 是 Python 字符串下标，`end` 不包含在范围内。范围基于当前 `current_text`。当文案变化时，第一版只保留仍落在新文本长度内的范围，并裁剪越界的 `end`；空范围会被移除。

新增方法：

- `set_text_color_range(start, end, color)`：设置或覆盖一个选区颜色。
- `clear_text_color_range(start, end)`：清除选区内局部颜色。
- `get_text_color_ranges()`：返回可序列化副本。

设置颜色时会合并相邻且颜色相同的范围。若新范围覆盖已有范围，重叠部分以新颜色为准，未重叠部分保留原颜色。

## UI

在文字属性面板的文字内容区增加两个紧凑操作：

- `选区颜色`：当内嵌文案编辑框有选中文本时启用，打开现有 A2 颜色选择器，把选区写入 `text_color_ranges`。
- `清除选区色`：当有选中文本时启用，移除选区范围内的局部颜色。

内嵌编辑框仍使用 `QTextEdit.setAcceptRichText(False)`。第一版不要求编辑框内直接显示彩色富文本，颜色效果以画布预览和导出为准。

## 渲染

文字渲染保持现有测量、对齐、自动文本框、描边、行距、字距和竖排逻辑。局部颜色只影响主文字填充层。

横排渲染中，将每一行映射回 `current_text` 的全局字符下标。无局部颜色的连续片段按现有全局颜色或渐变绘制；有局部颜色的片段按片段颜色绘制。存在字距时按字符逐个前进，避免片段切换导致定位变化。

竖排渲染中，每个字符同样映射到全局字符下标。命中局部颜色时使用片段颜色，否则沿用全局颜色或渐变。

当文字图层启用渐变时，局部颜色片段优先于渐变；未设置局部颜色的字符继续使用渐变。

## 缓存与序列化

`TextLayer.serialize()` 写入 `text_color_ranges`，`deserialize()` 对缺失字段使用空列表。`duplicate()` 复制该列表。

`FastRenderer` 的文字图层缓存键加入 `text_color_ranges` 的稳定表示，避免修改局部颜色后复用旧缓存。

样式批量套用暂不复制 `text_color_ranges`，因为它是文案内容级数据，不属于全局样式。复制图层和项目保存会保留它。

## 验证

自动测试优先覆盖：

- 范围设置、覆盖、清除、合并和越界裁剪。
- 序列化、反序列化和复制图层保留局部颜色。
- 渲染输出中设置片段与未设置片段出现不同颜色。

手动验证：

- 启动 `python main.py`。
- 新建文字图层，选中部分文字设置颜色，画布预览变化。
- 保存 `.cmp` 后重新打开，局部颜色仍存在。
- 导出 PNG，检查局部颜色与预览一致。

## 自检

- 无待定项或占位符。
- 数据模型与 UI、渲染、序列化说明一致。
- 第一版范围只包含局部颜色，没有引入完整富文本。
- 旧文件兼容路径明确。
