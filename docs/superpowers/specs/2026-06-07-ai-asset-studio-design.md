# AI素材工坊第一版设计

## 目标

在现有「批图王」里新增一个非阻塞的 AI 素材生产入口，完成「API 生成图片 -> 保存本地素材库 -> 可选基础抠图/分割 -> 导入为图片图层文件夹」的闭环。

第一版只生产素材，不改现有批量导出核心逻辑。

## 入口

- 主工具栏新增 `AI素材` 按钮，放在添加图层相关按钮附近。
- 菜单新增 `图层 -> AI生成素材...`。
- 第一版暂不做图层右键入口，避免改动图层列表右键菜单。

## UI

新增 `AI素材工坊` 窗口，使用非模态对话框。窗口包含：

- API 设置：Base URL、Endpoint、API Key、模型名。
- 生成参数：提示词、反向提示词、数量、尺寸、素材组名称。
- 处理模式：仅生成、生成后基础抠图、生成后基础抠图并自动分割。
- 结果列表：显示输出文件路径、状态和错误信息。
- 导入动作：将成功输出目录作为当前文档的新图片图层随机图像源。

API Key 不写入项目文件，只通过本机 `QSettings` 保存。

## 数据流

1. 用户填写参数并点击生成。
2. 后台任务调用 API。
3. 服务解析常见图片返回格式：URL、base64、OpenAI 风格 `data` 数组。
4. 原图保存到本地 AI 素材库。
5. 按处理模式生成 `cutout` 或 `segments` 子目录。
6. 用户点击导入后，当前文档新增一个图片图层，图层 `image_source` 指向对应输出目录，`is_folder=True`。

## 本地素材库

素材保存在用户应用数据目录下：

```text
批图王/ai_assets/<素材组>_<时间戳>/
  raw/
  cutout/
  segments/
  metadata.json
```

## 基础抠图和分割

第一版提供确定性基础处理：

- 对透明图直接按 alpha 裁剪。
- 对黑底/白底图，按角落背景色估计背景，生成前景 mask。
- 分割使用连通域，过滤过小组件，输出透明 PNG。

AI 语义归组保留接口和元数据字段，但第一版不接入视觉判断流程，避免 API 类型不明确导致范围失控。

## 错误处理

- 网络失败、API 返回非 2xx、返回格式无法解析时，在结果列表显示错误。
- 单张图片处理失败不影响其他图片。
- 后台任务完成后恢复按钮状态。

## 验证

- 单元测试覆盖本地目录命名、常见 API 响应解析、黑底分割。
- 手动验证 `python main.py` 能启动，菜单和工具栏入口可打开窗口。
- 无 API Key 时可通过本地服务测试解析和保存逻辑；真实云雾 Key 由用户配置后验证。
