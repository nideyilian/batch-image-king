# AI素材工坊第一版设计

## 目标

在现有「批图王」里新增图层级 AI 生图能力，完成「全局 API 设置 -> 当前图片图层填写提示词 -> API 生成图片 -> 保存本地素材库 -> 可选基础抠图/分割 -> 写回当前图层图片源」的闭环。

第一版只生产素材，不改现有批量导出核心逻辑。

## 入口

- 主工具栏新增 `AI接口设置` 按钮，管理多个接口配置档案。每个档案独立保存 Base URL、生图 Endpoint、模型 Endpoint、API Key、认证方式和模型字段。
- 菜单新增同一全局设置入口。
- 每个图片图层的属性面板新增 `AI生图` 模块，负责提示词、数量、尺寸、处理模式和生成动作。

## UI

新增全局 `AI接口设置` 窗口，使用非模态对话框。窗口包含：

- 接口档案的新增、删除和切换。
- Base URL、生图 Endpoint、模型 Endpoint、API Key、认证方式和模型字段。
- 使用模型 Endpoint 自动拉取模型列表。
- 手动添加或删除模型 ID，补充不支持模型列表接口的平台。

接口档案和 API Key 不写入项目文件，只通过本机 `QSettings` 保存。提示词、反向提示词、生成数量、尺寸和处理模式位于每个图片图层属性面板的 `AI生图` 模块。图层模块通过接口和模型下拉框选择本次生成所用配置，并允许直接输入自定义模型 ID。

## 数据流

1. 用户在工具栏设置全局 API 参数。
2. 用户选择图片图层，在该图层属性面板填写 AI 生图参数并点击生成。
2. 后台任务调用 API。
3. 服务解析常见图片返回格式：URL、base64、OpenAI 风格 `data` 数组。
4. 原图保存到本地 AI 素材库。
5. 按处理模式生成 `cutout` 或 `segments` 子目录。
6. 当前图层的 `image_source` 指向对应输出目录，`is_folder=True`，成为现有随机图片源。

## 本地素材库

素材保存在用户应用数据目录下：

```text
批图王/ai_assets/<素材组>_<时间戳>/
  raw/
  cutout/
  segments/
  metadata.json
```

## 基础抠图和分割

第一版提供确定性基础处理：

- 对透明图直接按 alpha 裁剪。
- 对黑底/白底图，按角落背景色估计背景，生成前景 mask。
- 分割使用连通域，过滤过小组件，输出透明 PNG。

AI 语义归组保留接口和元数据字段，但第一版不接入视觉判断流程，避免 API 类型不明确导致范围失控。

## 错误处理

- 网络失败、API 返回非 2xx、返回格式无法解析时，在结果列表显示错误。
- 单张图片处理失败不影响其他图片。
- 后台任务完成后恢复按钮状态。

## 验证

- 单元测试覆盖本地目录命名、常见 API 响应解析、黑底分割。
- 手动验证 `python main.py` 能启动，菜单和工具栏入口可打开窗口。
- 无 API Key 时可通过本地服务测试解析和保存逻辑；真实云雾 Key 由用户配置后验证。
