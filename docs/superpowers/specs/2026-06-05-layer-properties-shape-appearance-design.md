# 图层属性形状与外观面板设计

## 目标

优化右侧图层属性面板中“形状设置”和“矢量与填充（高级）”两个模块的信息架构，减少默认可见控件数量，让常用操作更靠前，同时不改变现有图层模型、渲染逻辑、保存格式或批量导出行为。

## 成功标准

1. “形状设置”展示为“形状”，优先显示形状类型、圆角和预览。
2. 形状类型从下拉框优化为紧凑的分段按钮：矩形、梯形、圆形、五边、六边。
3. 矩形和圆形默认隐藏不相关参数；梯形只显示上底、下底、斜边方向；五边和六边只显示旋转角度、圆角半径。
4. “矢量与填充（高级）”改为“外观”，将填充改成“无 / 纯色 / 渐变”模式。
5. 未启用的填充或描边详细控件默认不占用大量空间；启用后显示对应颜色、粗细、对齐等必要项。
6. 描边连接、端点、虚线段长和间隔保留为“高级线条”区域，默认折叠。
7. 现有属性更新函数、历史记录保存、文档刷新、颜色选择和多选图层描边更新能力保持可用。

## 设计

外层仍使用现有 `CollapsibleGroupBox`，保持图层属性模块可拆分/合并能力。内部只调整 `app/ui/layer_properties.py` 中的布局和显隐逻辑，避免拆分大文件或重写模型。

形状模块使用一组可互斥按钮作为形状类型选择入口。现有 `shape_type_combo` 可保留为隐藏兼容控件，避免大范围改动同步逻辑；按钮点击时仍调用 `update_shape_type()`，同步时也更新按钮选中状态。

外观模块用填充模式按钮替代两个独立复选框的默认入口。选择“无”会关闭纯色和渐变；选择“纯色”启用纯色填充并显示填充色；选择“渐变”启用渐变填充并显示起点色、终点色、角度和不透明度。原有复选框可以隐藏保留，供现有更新函数继续复用。

描边模块默认显示开关、粗细、对齐和颜色。高级线条区域使用内部折叠组承载连接、端点、虚线段长和间隔。

## 验证

1. 新增一个轻量 Qt 结构测试，验证新控件存在、默认分组标题正确、填充模式显隐方法可用。
2. 运行该测试，先确认在实现前失败，再实现并确认通过。
3. 运行 `python -m py_compile app/ui/layer_properties.py`。
4. 如环境允许，使用 `QT_QPA_PLATFORM=offscreen` 实例化 `LayerPropertiesPanel(None)`，确认不会崩溃。
