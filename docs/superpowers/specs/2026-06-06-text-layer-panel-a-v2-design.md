# 文字图层属性面板 A v2 设计

## 目标

优化文字图层属性面板的信息架构，把现有“文字突出 / 文字内容 / 核心参数 / 位置和变换 / 背景和渐变”重组为更容易扫描和操作的模块：文字内容、字体、排版、外观、位置和尺寸。

本次只调整 `app/ui/integrated_text_panel.py` 的 UI 布局、控件分组、显隐和摘要，不改变 `TextLayer` 模型、渲染逻辑、保存格式、批量导出行为。

## 成功标准

1. “文字突出”不再作为独立空卡占据首屏；创建、编辑、绑定入口合并到“文字内容”模块。
2. 原“核心参数”拆分为“字体”“排版”“外观”三个模块。
3. “字体”模块展示字体搜索/选择、常用字体，并把最近字体放入折叠摘要或更轻量区域。
4. “排版”模块展示字号、粗体、斜体、对齐、竖排、行距、字距、文本框自动适配和边距。
5. “外观”模块展示文字填充、透明度、描边、背景；文字填充和背景都使用“无 / 纯色 / 渐变”模式入口。
6. 描边、背景、渐变的详细参数只在启用或选择对应模式后显示。
7. “位置和变换”改为“位置和尺寸”，把 X/Y 与 W/H 分为两个小组，并在标题栏展示坐标和尺寸摘要。
8. 自动适配文本框开启时，W/H 仍沿用现有禁用逻辑，并在 UI 中通过尺寸小组体现“自动适配”状态。
9. 现有信号处理函数、字体加载、最近字体、文本编辑、绑定模式、位置/尺寸更新、背景渐变更新保持可用。

## 设计

继续使用现有 `IntegratedTextPanel` 类，不拆分文件，不新增模型字段。布局层面保留现有控件变量名和信号处理函数，优先通过新的容器和小 helper 来重组控件。

外观模块使用两个模式按钮组：

- `text_fill_mode_buttons`：无、纯色、渐变。纯色使用现有 `text_color`；渐变使用现有 `gradient_*` 控件。
- `background_mode_buttons`：无、纯色、渐变。纯色使用现有 `bg_*` 控件；渐变使用现有 `gradient_*` 控件。

由于当前模型只有一套渐变属性，文字渐变和背景渐变不新增第二套数据；UI 只负责让入口更清楚，保持原有属性含义。

位置和尺寸模块使用现有 `x_spin`、`y_spin`、`width_spin`、`height_spin`，增加标题摘要标签。`update_ui()`、位置变化和尺寸变化后同步摘要。

## 验证

1. 新增轻量 Qt 结构测试，实例化 `IntegratedTextPanel`，验证模块标题、按钮组、位置摘要 helper 和显隐 helper 存在。
2. 运行测试，先确认实现前失败，再实现并确认通过。
3. 运行 `python -m py_compile app/ui/integrated_text_panel.py`。
