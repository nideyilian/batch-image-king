# QML 画布直接编辑设计

## 目标与范围

第二阶段把 QML 工作台从“通过列表和属性框编辑”推进到“直接操作画布”。用户可以点击画布选择最上层可见图层，拖动图层，使用四角控制点调整尺寸，通过鼠标滚轮缩放视图，并一键恢复适配比例。属性面板新增图层名称和旋转角度；顶部左对齐、水平居中、垂直居中按钮接入真实模型。

本阶段保持单选模型，不加入多选、参考线、吸附、图层组直接变换和批量导出。旋转后的图层仍可选择和移动；四角缩放按图层未旋转的逻辑矩形计算，避免在首版中引入带旋转锚点的仿射变换协议。

## 交互与命令边界

QML 负责一次指针手势内的瞬时几何状态。按下时记录图层的 `x/y/width/height`，移动时只更新选框；松手时调用一次 `applySelectedGeometry()`。这样拖动过程不会创建大量历史快照，也不会让后台预览渲染和主线程鼠标事件争抢文档锁。提交后 ViewModel 统一失效缓存、标记文档、保存历史并请求新预览。

画布命中由 `WorkspaceViewModel.selectLayerAt()` 完成。它从图层栈顶向下检查可见、未锁定图层，并把画布坐标逆旋转到图层局部坐标后执行矩形命中。空白区域调用 `clearSelection()`。该命中协议只依赖模型几何，不引用 QWidget 画布实例。

## ViewModel 扩展

新增选择属性 `selectedRotation` 和 `selectedCanRotate`。文字图层当前没有通用旋转字段，因此旋转控件对这类图层禁用，避免写入无法序列化的临时属性。

新增命令包括：

- `setSelectedName(name)`：校验非空名称并刷新图层列表。
- `setSelectedRotation(degrees)`：只操作支持 `rotation` 的图层。
- `selectLayerAt(x, y)` 与 `clearSelection()`：维护单选状态。
- `applySelectedGeometry(x, y, width, height)`：一次提交位置和尺寸。
- `alignSelected(mode)`：支持 `left`、`hcenter` 和 `vcenter`。

所有模型写入继续复用文档锁。几何、旋转、显隐变化递增命中版本并失效渲染缓存；名称变化只刷新列表和文档状态。

## QML 结构

画板内部增加覆盖整个画布的 `MouseArea`，根据指针与四个控制点的距离选择移动或缩放模式。选框绑定瞬时几何或 ViewModel 几何，并根据选中图层旋转显示。锁定图层不进入直接变换状态。

滚轮以 5% 步长调整 `zoomValue`，范围保持 35% 到 200%；点击百分比恢复 78% 的适配基准。所有控制点尺寸按画布缩放倒数计算，保证不同缩放下具有稳定的屏幕点击面积。

## 验证

- 单元测试覆盖逆旋转命中、空白清选、一次几何提交只需一次撤销、锁定保护、名称、旋转和对齐。
- QML 离屏测试继续验证窗口可渲染。
- 生成 1280x760 和 1600x960 截图，检查控制点、属性值、画布边界和响应式布局。
- 保留现有单元测试基线，不修改既有 `FastRenderer` 白名单失败。
