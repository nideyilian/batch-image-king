# QML 专业影像工作台原型设计

## 目标

创建一个与现有 QWidget 主程序完全隔离、可以直接运行和截图的 Qt Quick/QML 原型，用于验证批图王迁移到 QML 后的视觉质量、信息密度与核心编辑工作流。原型不读取或写入 `.cmp`，不调用正式渲染和批量导出代码。

## 设计方向

采用克制的专业影像工作台，而不是卡片化后台或营销页面。基础色为中性石墨黑，主操作色为低面积青绿色，琥珀色仅用于输出状态。字体优先使用 MiSans 与 HarmonyOS Sans SC，图标使用 Windows 自带的 Segoe Fluent Icons。

界面保持四个稳定区域：顶部命令区、左侧工具与图层、中央多标签画布、右侧上下文属性。画布使用真实产品摄影和排版图层展示编辑状态，避免空白占位画布无法判断界面承载力。

## 原型组件

- 顶部品牌、文件菜单、撤销/重做、创建图层、对齐和导出命令。
- 文档标签、活动文档状态和保存状态。
- 垂直工具栏，覆盖选择、手型、文字、形状、取色和缩放语义。
- 图层列表，支持选中、可见性和锁定状态的视觉反馈。
- 中央画布，包含缩放、网格、参考线、选区和控制点。
- 属性检查器，包含变换、外观、随机化等高频参数。
- 底部缩放、颜色信息、性能状态和非阻塞操作提示。

## 交互与数据流

QML 内部 `ListModel` 保存原型图层状态。选择图层会同步画布选区和属性面板标题；缩放控件改变画布比例；工具、导出和新增图层操作显示非阻塞提示。正式迁移时，这些本地状态应替换为 Python ViewModel 暴露的只读属性和命令，不应让 QML 直接访问 `Document` 的内部列表。

## 失败边界

原型启动器在 QML 根对象创建失败时返回非零退出码。截图模式在指定时间抓取根窗口并校验保存结果，便于 CI 或本地离屏验证。外部摄影素材固定保存到原型目录，运行时不依赖网络。

## 验证标准

- `python prototypes/qml_workbench/main.py` 可独立启动。
- `--screenshot` 能生成非空 PNG。
- 1600×960 桌面视口与 1280×760 紧凑视口无控件重叠、文字溢出或空白画布。
- 原型文件不被正式入口、打包配置或业务模型导入。
