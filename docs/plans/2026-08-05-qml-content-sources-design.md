# QML 内容源与批量变量设计

## 目标

让 QML 工作台中新建的文档具备真实批量生产能力。用户可以把图片图层连接到单张图片或素材文件夹，也可以直接编辑文字图层并决定换行是随机候选还是排版内容。完成后，上一阶段的批量导出不再依赖从旧界面打开预先配置好的项目。

## 方案选择

可选方向包括图层组织、效果面板和内容源编辑。本阶段选择内容源编辑，因为它是批量导出产生差异化结果的前置条件。图层分组和效果继续沿用现有模型，不在本阶段扩大范围。

## 交互设计

右侧属性栏根据选中图层类型显示上下文区块。

图片图层显示“内容源”：

- 当前模式为单文件或素材文件夹。
- 路径以单行省略形式显示。
- 提供选择文件、选择文件夹两个明确命令。
- 文件夹模式显示可用素材数量、当前预览文件，并提供“换一张”图标按钮。
- 新增素材文件夹也可以从顶部工具栏直接创建图片图层。

文字图层显示“文字内容”：

- 多行编辑器直接编辑图层内容。
- 模式使用分段控件：“按行随机”把每个非空行作为候选；“整段排版”保留真实换行并把全文视为一条文案。
- 显示候选数量，并提供字号输入。
- 编辑器失去焦点或按 `Ctrl+Enter` 时提交，避免每次按键触发高成本渲染。

控件沿用现有暗色令牌、4-6 px 圆角和紧凑信息密度。图片与文字区块不会同时显示，也不使用嵌套卡片。

## 架构

所有业务写入集中在 `WorkspaceViewModel`：

- 暴露图层类型、图片源、图片源数量、当前文件、文字内容、文字模式、候选数量和字号属性。
- 使用专用 Slot 校验并更新内容源。
- 复用现有文档锁、历史基线、缓存失效、修改状态和预览调度。
- QML 只绑定属性并调用命令，不直接持有 `Layer` 或 `TextLayer`。

图片文件夹创建与图片文件创建共享尺寸计算逻辑。文件夹会使用按名称排序的首张支持图片作为初始预览，之后由现有批量导出管线负责随机选择。文字更新调用 `TextLayer` 的解析与缓存接口，确保序列化和批量导出读取同一份候选数据。

## 错误处理

- 路径不存在或类型不符时不修改图层。
- 文件夹没有支持的图片时拒绝创建或替换。
- 非图片图层不能调用图片源命令。
- 非文字图层不能调用文字命令。
- 锁定图层和批量导出期间拒绝修改。
- 失败通过状态栏和 toast 反馈，原内容保持不变。

## 验收标准

- 可从工具栏选择素材文件夹并创建真实图片图层。
- 可在单文件和文件夹之间替换图片源。
- 文件夹素材数量与当前预览文件正确显示，可手动换图。
- 可编辑多行文字并切换按行随机/整段排版。
- 内容源和文字配置保存为 `.cmp` 后可正确恢复。
- 撤销/重做、预览、批量导出互斥和现有 QML 功能保持正常。
