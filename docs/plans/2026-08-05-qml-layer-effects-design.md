# QML 图层外观效果设计

## 目标

将 QML 工作台右侧属性面板中仍为静态展示的高频外观能力接入真实图层模型：混合模式、描边和圆角。修改后必须立即刷新预览，支持撤销/重做，并在 `.cmp` 保存加载后保持一致。

## 范围选择

本阶段聚焦底层模型已经稳定支持、且编辑器用户高频使用的三类能力：

- 图片与异形图层：混合模式、描边、圆角。
- 文字图层：文字描边。
- 所有支持的图层：锁定保护、批量导出互斥、原子历史记录。

颜色叠加、渐变叠加、阴影和高级描边位置不在本阶段实现。它们需要更多颜色停止点、透明度与几何参数，适合在基础效果命令稳定后单独接入。

## 交互设计

“属性”页的外观区显示真实混合模式，并使用紧凑下拉选择器提供正常、正片叠底、滤色、叠加、柔光和强光六个常用模式。文字图层没有底层混合属性时显示“正常”且禁用选择，不创建兼容性假属性。

“效果”标签对有选中图层始终可用：

- 描边区显示启用开关、宽度输入和颜色。颜色既可点击色板快速选择，也可打开系统颜色选择器。
- 圆角区仅对图片/异形图层显示，提供半径输入和 0、12、24、48 四个快捷预设。
- 不支持的效果不显示，不用灰色占位制造虚假能力。

数值输入在提交时归一化。描边宽度限制为 1-128 px，圆角限制为 0 到图层短边的一半。颜色接受 `#RRGGBB` 或 `#RRGGBBAA`，界面标准化显示大写 `#RRGGBB`。

## 架构与数据流

`WorkspaceViewModel` 暴露效果能力、当前值和修改命令。混合模式在 QML 使用稳定字符串 ID，在 ViewModel 中映射到底层整数值；描边与圆角直接使用现有图层属性。所有修改复用 `_set_layer_attr()`，从而统一处理锁定、文档修改状态、缓存失效、历史快照、列表通知和预览刷新。

QML 新增一个符合现有暗色设计系统的紧凑 `SelectBox` 组件。效果页只绑定 ViewModel，不直接访问 Python 图层对象。系统 `ColorDialog` 返回的颜色先转为十六进制字符串，再交给 ViewModel 校验。

## 错误与状态

- 未选择图层、图层锁定或批量导出进行中时，修改命令返回失败并保持文档不变。
- 不支持的图层类型不接受混合模式或圆角命令。
- 未知混合模式与非法颜色被拒绝，不回退为其他值。
- 相同值视为成功但不额外创建历史快照。
- 撤销/重做后 ViewModel 重新读取恢复后的图层实例，界面与预览同步更新。

## 验收标准

- 图片图层的混合模式、描边和圆角可由 QML 修改并立即影响真实预览。
- 文字图层描边可修改，混合与圆角入口不会误启用。
- 所有成功修改均可一次撤销和重做。
- 锁定、无选择和导出状态正确阻止修改。
- `.cmp` 保存加载后效果值保持一致。
- 1280x760 与 1600x960 下效果面板无挤压、重叠或横向滚动。
