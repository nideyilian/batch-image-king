# QML 图层参数侧边栏设计

## 目标

新版 QML 侧边栏沿用旧版已经验证的两级信息架构，顶层只保留“基本参数”和“更多参数”。用户不再需要判断“属性”和“效果”的差别；同一个模型字段也只保留一个编辑入口。

## 信息架构

基本参数按高频程度组织：基本属性、图像源、高级设置、形状、外观。文字图层继续在基本参数中按能力展示文字内容、字体和排版；图层组只展示组属性。外观下延续现有文字填充、背景、阴影、发光、描边、叠加和圆角控件。

更多参数按低频任务组织：图层分身、图层变换、随机变换。AI 生图保留在后续迁移范围，本轮不接入新版侧边栏；分身和随机变换继续使用现有能力判断；图层变换集中旋转和翻转，避免它们同时出现在图片布局与基本属性中。

## 组件与状态

现有 `PropertySection`、`InspectorRow`、`ValueBox`、`SelectBox`、`ToggleSwitch` 和按钮组件继续作为唯一控件实现。两个页签共享一个滚动容器，分区通过 `inspectorTab` 与图层能力动态显隐，并使用布局顺序而不是复制控件。

## 验收

- 顶部只有“基本参数 / 更多参数”两个页签。
- 普通图片图层的基本页出现五个核心分区，更多页出现三个已接入的低频分区。
- 旋转和翻转只出现在“图层变换”。
- 不支持的分区自动隐藏，切换页签后滚动位置回到顶部。
