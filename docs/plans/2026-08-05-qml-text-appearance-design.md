# QML 文字外观设计

## 目标

在 QML 工作台中补齐文字图层已经由真实模型和渲染器支持的外观能力，使文字填充、渐变、背景、描边和局部颜色可以参与撤销、保存、预览与导出。

## 本阶段范围

- 文字纯色填充，支持 RGBA 十六进制颜色。
- 文字渐变填充：线性、径向、角度三类。
- 线性渐变方向：水平、垂直、左上到右下、右上到左下。
- 径向渐变中心 X/Y。
- 文字背景：启用、颜色、透明度、背景扩展距离。
- 文字描边继续复用已有通用效果面板。
- 局部颜色：在整段排版模式中，为当前文字选区设置或清除颜色。

阴影不在本阶段接入。当前 `TextLayer` 只有兼容序列化占位字段，新建图层没有正式属性，`TextLayerRenderMixin` 也不渲染阴影。后续需要先解决阴影边界扩张、自动文本框、横竖排和超采样的一致性，再提供 UI。

## 方案比较

1. 只接入纯色与描边：改动最小，但文字设计流程仍不完整。
2. 接入真实可用的完整外观主路径：覆盖填充、三类渐变、背景、描边和局部颜色，推荐。
3. 复刻旧 QWidget 全部控件：会暴露未生效的阴影/发光占位字段，也会带入旧面板的信息密度问题。

采用方案 2。它不修改渲染算法，只通过 `WorkspaceViewModel` 映射 `TextLayer` 正式属性，因此预览、单图导出和批量导出继续共用既有渲染结果。

## 数据流

```text
QML 文字外观控件
  -> WorkspaceViewModel Slot
  -> _change_selected_text()
  -> TextLayer 正式属性 / 局部颜色 API
  -> Document history + render cache invalidation
  -> FastRenderer / DocumentRenderer
```

颜色统一使用 `#RRGGBB` 或 `#RRGGBBAA`。背景透明度写回 `background_color` 的 Alpha 通道。渐变类型和方向在 QML 使用稳定的小写标识，在模型层映射到现有枚举名称。

## 界面结构

“效果”标签页在现有描边之前新增：

- “文字填充”：纯色/渐变分段模式；颜色色块；渐变类型、方向、起止色和径向中心。
- “文字背景”：启用开关、颜色、透明度和扩展距离。

“文字内容”区在编辑器下方增加选区颜色与清除按钮。按钮只在整段排版、存在非空选区、图层未锁定且没有导出任务时可用。候选文案模式不开放局部颜色，避免选区索引映射到错误候选。

控件沿用现有暗色工具型视觉、颜色色块、紧凑数值输入和分段模式控件，不增加说明卡片或装饰性元素。

## 边界与错误处理

- 非文字图层、锁定图层和导出运行中拒绝修改。
- 无效颜色、渐变类型、方向和空选区拒绝写入。
- 背景透明度钳制为 `0..100%`，扩展距离钳制为 `-50..50 px`，径向中心钳制为 `0..100%`。
- 局部颜色索引钳制到当前文案长度；候选模式明确拒绝。
- 当前渐变模式不会删除纯色值，切回纯色时恢复上次纯色。

## 验证

- 单元测试覆盖属性映射、范围钳制、模式校验、锁定拒绝、撤销重做与 `.cmp` 往返。
- 渲染测试验证纯色、渐变、背景与局部颜色改变真实像素。
- QML 烟雾测试覆盖全部控件绑定和选区颜色动作。
- 1280x760 与 1600x960 截图检查色块、长摘要、渐变参数、滚动与禁用状态。
