# QML 图片适配与翻转设计

## 目标

让 QML 工作台中的普通图片图层和异形图片图层能够完整控制图片在图层框内的适配方式、裁剪锚点和镜像方向。所有调整必须作用于真实图层模型，进入统一预览与导出管线，并支持撤销、重做和 `.cmp` 保存加载。

## 方案选择

现有 `Layer` 已提供 `fit_mode`、`crop_direction`、`flip_horizontal` 和 `flip_vertical`，图片加载、裁剪、变换与序列化也已支持这些字段。因此本阶段采用轻量桥接方案：只在 `WorkspaceViewModel` 暴露经过验证的能力属性与命令，并在 QML 属性面板绑定这些接口。

不在 QML 中自行裁剪像素，也不新增第二套适配枚举。这样普通图片和 `ShapedLayer` 可复用相同业务逻辑，预览、单图导出和批量导出自然保持一致。拖动画面来调整焦点、自由裁剪框和人脸智能取景属于独立裁剪编辑器，留到后续阶段。

## 属性与交互

适配模式使用稳定字符串 ID：

- `crop`：等比放大并填满图层框，超出部分裁剪。
- `fit`：等比缩小或放大，完整显示图片，剩余区域透明。
- `original`：保持原图像素尺寸，在图层框内居中。

只有 `crop` 模式显示裁剪方向，方向 ID 为 `center`、`top`、`bottom`、`left`、`right`。属性面板用下拉菜单选择适配模式，用紧凑的五向定位控件选择裁剪锚点。水平和垂直翻转使用两个图标按钮，选中状态必须清楚可见，并提供悬停说明。

文字图层不显示图片适配区域。普通图片和异形图片都显示该区域；文件夹素材源与单图素材源行为一致。图层锁定或导出操作阻塞时，所有控件禁用。

## 数据流与历史

QML 调用 `WorkspaceViewModel.setSelectedFitMode()`、`setSelectedCropDirection()` 和两个翻转命令。ViewModel 将字符串 ID 映射为模型中的整数常量，再复用 `_set_layer_attr()` 完成：

1. 校验当前选择、能力、锁定状态与输入 ID。
2. 建立历史基线并保存一次原子操作。
3. 更新模型属性并使图层缓存失效。
4. 标记文档修改、刷新选择状态和图层列表。
5. 强制请求真实预览。

适配模式改变后保留用户之前选择的裁剪方向，切回 `crop` 时继续使用。无效 ID、无图层、文字图层、锁定图层或导出进行中返回 `False`，不产生历史记录也不修改文档。

## 测试与验收

- 普通图片与异形图片均发布正确的 capability 和当前状态。
- 三种适配模式、五种裁剪方向及两种翻转可修改并拒绝非法输入。
- 每次有效修改可撤销、重做；相同值不重复增加历史。
- 锁定图层和文字图层不能通过命令修改图片属性。
- `.cmp` 保存加载后四项属性保持一致。
- 使用非对称测试图验证裁剪锚点和翻转确实改变真实预览像素。
- 1280x760 与 1600x960 下属性面板无裁切、重叠和横向溢出。
