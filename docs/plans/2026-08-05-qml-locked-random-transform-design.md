# QML 比例锁定与随机变换设计

## 目标

完成 QML 图片图层的基础变换闭环：普通图片和异形图片可以锁定当前宽高比，并通过尺寸输入或画布四角拖拽进行等比缩放；同时可以配置随机位置、随机缩放和随机旋转，让配置进入真实批量导出链路，并在编辑器中生成一组可见预览。

## 方案选择

比例锁定采用双层约束。`WorkspaceViewModel` 是数据规则的最终入口：锁定后修改宽度会同步计算高度，修改高度会同步计算宽度，所有变化作为一次历史操作保存。QML 画布在拖动四角时使用相同宽高比实时计算临时框，避免松手后突然跳变。模型继续使用现有 `aspect_ratio_locked` 字段，不新增冗余比例字段；锁定时的比例始终取当前宽高。

随机变换复用 `Layer` 已有的七个配置字段与四个运行时字段。三个随机项独立启用：位置使用对称像素范围，缩放使用最小/最大百分比，旋转使用对称角度范围。ViewModel 负责范围校验、历史、持久化和“换一组”预览命令。运行时抽样值不写入项目文件，批量导出仍按现有 `DocumentRandomizer` 和预计算流程为每张结果重新生成。

审计发现当前实际使用的 `layer_transform_mixin.py` 在模块拆分时只保留了随机位置，遗漏了随机缩放与旋转的像素处理。本阶段恢复这段真实渲染逻辑：手动翻转/旋转后，按图层中心应用随机缩放，再在固定画布内应用随机旋转；缩小产生透明边缘，放大裁掉超出图层框的部分。使用预乘 Alpha 重采样，避免透明边出现黑白晕。

## 交互与界面

“变换”区的尺寸行增加锁链图标按钮，锁定时使用强调色。随机变换作为独立属性区放在图片布局之后，保持批量工作流中的高可见性：

- 位置：开关与 `± px` 范围。
- 缩放：开关与最小/最大百分比。
- 旋转：开关与 `± °` 范围。
- 预览：显示当前偏移、缩放与旋转摘要，并提供刷新图标。

锁定图层或导出运行时所有控件禁用。文字图层暂不显示该区域，因为现有文字随机变换接口是兼容空实现，不应制造无效控件。

## 错误处理与验收

无选择、错误图层类型、锁定状态和导出阻塞均返回失败且不增加历史。位置范围限制为 `0..10000 px`，缩放限制为 `1%..1000%`，旋转限制为 `0..180°`；最小缩放超过最大值时同步提高最大值，最大值低于最小值时同步降低最小值。

验收要求覆盖普通图片与异形图层、文字图层拒绝、等比数值输入、四角拖拽、撤销重做、`.cmp` 往返、随机参数范围、真实随机缩放/旋转像素、批量随机化调用链以及 1280x760 和 1600x960 视觉检查。
