# QML 文字排版设计

## 目标

在 QML 工作台中补齐文字图层最常用的排版主路径，使字体、样式、对齐、间距、方向和文本框行为能够修改真实 `TextLayer`，并参与撤销、保存、预览与导出。

## 本阶段范围

- 字体家族：展示系统字体列表，支持输入过滤和选择。
- 字号：保留现有 `1..1000 px` 合约。
- 字体样式：粗体、斜体可独立切换，并组合为 `BOLD_ITALIC`。
- 段落对齐：左对齐、居中、右对齐。
- 排版方向：横排、竖排。
- 间距：行距 `50%..300%`、字距 `-20..100 px`。
- 文本框：内边距 `0..200 px`、自动适配开关。

文字填充、渐变、描边、背景、阴影和局部颜色不在本阶段处理，它们属于文字外观而不是排版主路径。

## 方案取舍

选择“字体与排版先闭环，外观后续独立接入”。一次接入全部文字能力会让属性面板和回归范围同时膨胀；只增加少量按钮又无法形成日常可用的排版流程。当前方案覆盖 QWidget 中最常用的排版字段，同时完整复用现有模型和序列化格式。

字体列表由 `TextLayer.get_system_fonts()` 提供并在 `WorkspaceViewModel` 中按实例缓存。当前字体始终置顶，即使系统扫描结果缺失也不会让旧项目失去可选状态。QML 使用专用可搜索字体选择器，不把数百个字体塞入普通下拉框。

## 数据流

```text
QML 字体/排版控件
  -> WorkspaceViewModel Slot
  -> _change_selected_text()
  -> TextLayer 正式属性
  -> Document history + render cache invalidation
  -> preview / export
```

`WorkspaceViewModel` 暴露字符串、数值和布尔属性。粗体与斜体由当前 `FontStyle` 推导，切换时重新组合为 `NORMAL`、`BOLD`、`ITALIC` 或 `BOLD_ITALIC`。对齐使用稳定的 `left`、`center`、`right` QML 标识，写入模型时映射为枚举名称。

## 界面结构

文字内容区只保留内容和候选模式。其下新增两个独立的 `PropertySection`：

- “字体”：可搜索字体选择器；字号、粗体和斜体同一行。
- “排版”：三段式对齐控件；竖排和自动文本框开关；行距、字距和内边距使用紧凑数值输入。

界面沿用现有暗色工具型视觉系统、30px 控件高度和 4/8px 节奏。常用命令直接可见，高级数字参数保持可扫描，不新增卡片或说明性文字。

## 边界与错误处理

- 非文字图层、锁定图层和导出运行中拒绝修改。
- 字体名称去除首尾空白，空名称拒绝写入。
- 数值统一在 ViewModel 钳制，避免 QML 与模型出现不同约束。
- 自动文本框引起的宽高变化和属性修改记录在同一个历史状态中。
- 字体扫描失败时至少返回当前字体和平台默认字体，不阻塞文字编辑。

## 验证

- 单元测试覆盖属性读取、命令映射、范围钳制、锁定拒绝、撤销重做和 `.cmp` 往返。
- 渲染测试验证粗体/斜体、对齐、间距和竖排会改变真实输出或几何。
- QML 烟雾测试覆盖字体搜索控件和所有命令绑定。
- 1280x760 与 1600x960 截图检查字体长名称、输入后缀、滚动区域和禁用状态。
