# QML 原生图层编辑设计

## 目标

QML 工作台中的参数输入必须在获得焦点时保留当前值，并对单行参数自动全选，方便直接覆盖。文字内容等多行编辑器保留当前内容与光标编辑语义。文字图层、异形图层的创建和图层重命名不再打开旧 QWidget 或浅色窗口，全部使用现有深色 QML 视觉语言。

## 交互方案

共享输入组件以模型值作为失焦态真值；进入编辑态时复制当前值到编辑缓冲区，并停止模型绑定，不能恢复组件初始化时的空字符串。`ValueBox` 和 `FontSelectBox` 聚焦时全选当前内容；`ContentTextEditor` 聚焦时只保留内容，不自动全选。F2 展开右侧“变换”或“图层组”区，定位“名称”输入框并全选。

文字图层使用深色 QML 创建对话框承载旧版创建契约：名称、内容、绑定模式、字体、字号、颜色和对齐。异形图层使用同风格对话框承载名称、形状、位置、尺寸、可选内容源和形状专属参数。两者创建后都选中画布内的新图层，全部属性仍可在右侧检查器继续修改。

## 数据流与边界

QML 对话框把配置映射传给 `WorkspaceViewModel`。ViewModel 负责校验名称、尺寸、形状、颜色和可选文件/文件夹源，再创建真实 `TextLayer` / `ShapedLayer`，沿用文档历史、缓存失效、选中状态和预览刷新链路。QML 不直接构造 Python 模型。

项目级窗口如批量导出、绑定管理和尺寸匹配不属于图层创建/属性编辑，保持现状。标签页重命名也不在本次图层交互范围内。

## 验证

单元测试覆盖两类配置创建、空来源、文件夹来源、形状参数和历史记录。源码契约测试确保共享输入组件使用保值绑定，并确保 `Main.qml` 不再调用旧的文字/异形创建及图层重命名桥接。最后离屏渲染 1280x760 与 1600x960，检查对话框、输入值、裁切、重叠和暗色一致性。
