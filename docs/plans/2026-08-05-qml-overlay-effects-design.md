# QML 颜色与渐变叠加设计

## 目标

将 QML 工作台效果页中的颜色叠加与渐变叠加接入真实图层模型，使用户可以快速统一图片色调或应用双端线性渐变。所有修改必须即时进入预览，支持撤销/重做，并在 `.cmp` 保存加载后保持一致。

## 范围选择

本阶段仅接入底层普通图片和异形图层已经支持的叠加能力：

- 颜色叠加：启用、颜色、强度。
- 线性渐变叠加：启用、起始色、结束色、强度、角度。
- 方向预设：0°、45°、90°、135°。

颜色叠加与渐变叠加是互斥的填充模式。启用一种会在同一次历史操作中关闭另一种，与现有 QWidget 属性面板语义保持一致。多节点渐变、径向渐变、颜色停止点位置和混合模式不在本阶段实现。

## 交互设计

效果页按“描边、颜色叠加、渐变叠加、圆角”的顺序排列。每个叠加区使用标题摘要显示“关闭”或当前强度，展开后先显示启用开关。关闭时隐藏详细参数，减少面板噪声；启用后显示真实颜色色块和紧凑数值控件。

颜色色块点击后打开系统颜色选择器，旁边保留可编辑的 `#RRGGBB` / `#RRGGBBAA` 输入。渐变使用两个并排色块与方向箭头表达起止关系，不额外绘制装饰性预览卡。角度既可精确输入，也可使用四个固定方向预设。

文字图层没有通用颜色/渐变叠加模型，因此对应区块完全隐藏。无选择、锁定图层或批量导出时，控件不可修改。

## 架构与数据流

`WorkspaceViewModel` 以 capability 属性判断当前图层是否完整支持叠加字段，并暴露当前启用状态、颜色、强度和角度。颜色继续复用上一阶段的十六进制解析与格式化逻辑；渐变颜色命令只替换指定端点，保留另一端。

启用颜色或渐变时使用 `_set_layer_attrs()` 一次更新两个互斥标志，保证只生成一个历史快照。颜色、强度和角度修改复用 `_set_layer_attr()`，统一获得锁定保护、缓存失效、文档修改状态和预览刷新。

QML 只调用 ViewModel Slot，不直接访问 Python 图层对象。截图入口在演示效果模式下预置渐变，以便稳定验证色块、角度和实际画布结果。

## 验收标准

- 图片/异形图层可启用颜色叠加或渐变叠加，两者始终互斥。
- 强度限制为 0–100%，角度规范到 0–359°。
- 两个渐变端点颜色可独立修改，非法颜色不改变文档。
- 切换模式可一次撤销，重做后界面与预览恢复。
- 保存加载后所有叠加参数保持一致。
- 真实预览像素随颜色和渐变设置变化。
- 1280x760 与 1600x960 下效果面板无横向溢出、重叠或误导性占位。
