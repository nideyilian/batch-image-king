# QML 参数选项模块设计

## 目标

将需要用户理解“策略含义”的 2-3 个同级参数统一为点击选中模块，减少连续开关造成的扫描负担，同时保持批图王高密度生产工具的界面节奏。

## 设计边界

- 不修改 ViewModel、导出逻辑、随机变换逻辑和尺寸匹配数据结构。
- 不把简单二元状态、逐图层勾选或数值参数卡片化。
- 不在属性分区外增加嵌套卡片，只把选项本身作为可点击控件。
- 选中状态同时使用背景、边框、文字与勾选图标表达，不能只依赖颜色。

## 通用组件

新增 `app/qml/components/OptionTile.qml`，支持：

- `title`、`detail`：选项名称和简短说明。
- `selected`：由现有 ViewModel 状态单向绑定。
- `compact`：属性检查器或紧凑参数区使用较低高度。
- `exclusive`：互斥策略使用单选语义，独立策略使用复选语义。
- `activated()`：父级继续调用现有 setter，不在组件内部维护业务状态。

常规规格用于批量导出抽屉；紧凑规格用于随机变换和尺寸匹配。窄区域保持等宽三列，文字最多两行并省略，避免系统缩放后改变布局尺寸。

## 首批迁移

1. 单文档组合策略：从内联专用组件迁移到通用组件，视觉保持不变。
2. 随机变换：位置、缩放、旋转三项并排；启用后在下方显示对应范围。
3. 尺寸匹配：一对多、自动旋转、自动遮罩三项并排；自动遮罩参数继续按需显示。
4. 多标签批量导出：智能采样和遍历组合使用两列策略模块。
5. 高级导出性能：高性能管线、预读素材、独立 Worker 使用三列策略模块。

## 验证

- 静态测试确认组件注册、可访问语义和五个迁移区域。
- QML 离屏启动验证组件可加载、批量导出抽屉可渲染。
- 运行布局检测，确认没有新增溢出或任意间距问题。
