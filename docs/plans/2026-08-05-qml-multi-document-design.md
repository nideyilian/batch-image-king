# QML 多文档工作区设计

## 目标

将 QML 工作台从“单个可替换文档”升级为真实多文档会话。用户可以创建不同尺寸的画布、同时打开多个 `.cmp`、切换标签，并在关闭已修改文档时选择保存、放弃或取消。每个文档的选择、历史、路径和批量导出界面状态必须彼此隔离。

## 范围

本阶段包括：

- 应用级文档会话模型。
- 新建画布弹窗、常用尺寸和严格校验。
- 标签创建、切换和关闭。
- 修改文档的保存/放弃/取消确认。
- 每个文档独立的批量导出配置与完成状态。
- 打开项目时新增标签，不覆盖当前文档。

本阶段不包括标签拖拽排序、恢复上次会话、跨窗口文档、多标签批量导出和应用退出时的逐文档关闭流程。

## 架构

新增 `WorkspaceSessionViewModel`，以 `QAbstractListModel` 向 QML 暴露标签列表。每个会话保存一个真实 `Document` 引用，角色包括标题、路径、修改状态、画布尺寸和活动状态。

`WorkspaceViewModel` 继续作为唯一的活动文档桥接层。切换标签时，会话模型调用公开的 `activateDocument()`，由它统一解绑旧文档信号、替换图层模型、接入新文档信号并刷新预览。QML 不直接持有或切换 `Document`。

`BatchExportViewModel` 继续服务当前活动文档，但按文档身份保存配置和结果快照。在活动文档变化前保存旧状态，接入新文档后恢复其状态。正在导出时，工作区操作保持阻塞，标签切换、创建、打开和关闭均不可执行。

## 会话生命周期

### 新建

画布宽高必须是整数，范围为 16 到 32768 像素。弹窗提供 1080x1350、1080x1080、1920x1080 和 1080x1920 四个常用尺寸，也允许自定义。创建后初始化历史基线并作为新标签激活。

### 打开

打开文件时先在独立 `Document` 中加载；加载成功才加入会话，失败不改变现有标签。已经打开的规范化路径再次打开时，直接激活已有标签，避免同一文件产生两个可并行覆盖保存的会话。

### 切换

切换保留各 `Document` 自身的图层选择和历史。活动文档桥接层清除旧预览，递增预览版本并为新文档发起渲染，避免短暂显示前一标签内容。

### 关闭

未修改文档立即关闭。已修改文档发出确认请求，由 QML 展示保存、放弃、取消：

- 保存：有路径时保存成功后关闭；无路径时先打开保存对话框，成功后关闭。
- 放弃：不保存并关闭。
- 取消：保持会话不变。

关闭最后一个标签后自动创建默认 1080x1350 空白文档，保证编辑器始终有活动文档。

## 信号与状态一致性

会话模型监听每个文档的 `document_changed`，同时监听活动工作区的 `documentInfoChanged`，更新标题和修改标记。保存后即使底层没有额外发出 `document_changed`，活动标签也会立即刷新。

批量导出状态按文档保存以下字段：输出目录、数量、文件名模板、格式、去重开关，以及完成/取消/进度/阶段/最近文件/错误。运行态不做跨文档迁移，因为运行期间禁止切换。

## 错误处理

- 无效尺寸不创建会话，并显示明确错误。
- 文件加载失败不插入标签。
- 保存失败不关闭文档。
- 无效标签索引不改变活动文档。
- 导出运行期间所有会改变活动文档的操作返回失败。

## 验收标准

- 可创建至少三个不同尺寸的文档并保持各自图层与选择状态。
- 切换标签时 `WorkspaceViewModel.document`、图层模型、画布尺寸和预览同步变化。
- 重复打开同一路径只激活已有标签。
- 关闭修改文档必须经过保存、放弃或取消分支。
- 保存失败和取消不会丢失文档。
- 关闭最后一个标签后存在一个新的默认文档。
- 每个标签的批量导出配置和结果互不串用。
