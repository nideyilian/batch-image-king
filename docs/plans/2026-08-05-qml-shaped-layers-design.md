# QML 异形图层设计

## 目标

让 QML 工作台能够创建和编辑真实异形图层，而不是停留在禁用图标。用户选择一张图片后，可将其作为矩形、圆形、直角梯形、正五边形或正六边形内容创建，并在属性面板中切换形状和调整专用参数。结果必须进入现有预览、保存、撤销、单图导出和批量导出链路。

## 方案选择

现有 `ShapedLayer` 本质是“图片图层 + 形状蒙版”，已经由 `FastRenderer` 和普通图层效果管线支持。QML 不新增矢量对象或独立渲染器，也不把形状当成纯色装饰元素。

创建流程采用形状菜单加图片选择器：用户先选择目标形状，再选择图片。这样可以复用已有图片校验和尺寸计算，避免创建无内容的空壳图层。完整贝塞尔节点编辑、自由路径和纯色形状留到后续矢量编辑阶段。

## 创建行为

命令栏的异形按钮打开五种形状菜单，选择后打开图片文件对话框。`WorkspaceViewModel.addShapedLayer()` 负责：

- 校验形状标识和图片可读性。
- 按画布 60% 上限等比缩放源图并居中。
- 创建真实 `ShapedLayer`，设置当前图片路径和默认形状参数。
- 通过 `Document.add_shaped_layer()` 接入图层信号、历史、选择和渲染缓存。

直角梯形默认上底为图层宽度、下底为宽度的 80%，斜边在右侧。多边形默认旋转 0 度、圆角 0 像素。

## 属性与交互

`WorkspaceViewModel` 暴露异形类型、显示名称和专用参数。形状切换使用稳定字符串 ID：`rectangle`、`right_trapezoid`、`circle`、`pentagon`、`hexagon`。

属性面板使用紧凑分段网格显示五种形状。梯形状态下显示上底、下底和斜边方向；五边形或六边形状态下显示内部旋转和顶点圆角。参数范围：

- 梯形上下底为 1 到当前图层宽度。
- 多边形旋转规范为 0 到 359.9 度。
- 多边形圆角不超过短边的八分之一，与渲染器实际有效范围一致。

异形图层继续显示图片内容源、基础变换和现有图层效果。锁定时所有形状参数禁用。

## 数据一致性与错误处理

所有属性修改复用 `_set_layer_attr()` / `_set_layer_attrs()`，统一处理历史、缓存、修改标记和预览刷新。切换到梯形时，形状类型和默认上下底在一次历史操作中更新。

无效图片、未知形状、无选择、非异形图层、锁定图层或批量导出运行时返回失败且不改变文档。`.cmp` 继续使用现有 `ShapedLayer.serialize()` 和 `DocumentSerializer`，不改变文件格式。

## 验收标准

- 可从真实图片创建五种异形图层。
- 图层列表正确显示“异形”类型和图标。
- 形状与专用参数可修改、撤销和重做。
- 图片来源可替换，现有外观效果继续可用。
- 保存加载后仍为 `ShapedLayer`，形状参数保持一致。
- 圆形预览边角透明、中心有内容，导出走相同渲染结果。
- 1280x760 和 1600x960 下形状控件无裁切、重叠或横向溢出。
