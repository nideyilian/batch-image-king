# QML 高级图层属性内嵌设计

## 目标

“高级图层属性”不再打开独立的 QWidget 窗口。选中图层后，全部非 AI 属性都在 QML 工作台右侧的“属性/效果”检查器中直接编辑，并继续写入现有 `Layer`、`ShapedLayer` 和 `TextLayer` 模型。

## 方案选择

采用现有右侧检查器扩展方案，而不是新增弹窗或抽屉。基础属性保留当前布局；旧版面板独有的图层分身、元素铺排、智能裁剪、矢量四角圆角、描边对齐、连接、端点和虚线参数补入对应分区。菜单与工具栏的“高级图层属性”操作只负责定位和展开这些原生分区。

复杂的项目级流程，如绑定管理、尺寸匹配和批量导出，仍使用各自的生产窗口，因为它们不是单个图层的属性编辑器。

## 数据流

QML 控件调用 `WorkspaceViewModel` 的强类型属性和槽函数。槽函数统一经过 `_set_layer_attr()` / `_set_layer_attrs()`，负责锁定检查、历史记录、缓存失效、预览刷新和选择状态通知。QML 不直接修改 Python 图层对象，也不复制旧面板的业务状态。

分身首次启用时沿用旧版契约：默认的 `1x1` 自动变为 `2x2`。启用自定义分身尺寸时，以当前图层尺寸初始化。四角圆角更新时同步 `corner_radius` 为四角最大值，以保持现有渲染和旧项目兼容。

## 验证

- 单元测试覆盖全部新增 ViewModel 字段和修改入口。
- QML 源码契约测试确保不存在 `openAdvancedLayerProperties()` 调用，并存在内嵌分区。
- 运行全部 QML 测试、静态编译和离屏截图，检查右侧栏在 1280x760 与 1600x960 下的滚动、裁切和控件布局。
